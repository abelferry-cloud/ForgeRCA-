## 获取和验证

在仓库根目录运行：

```sh
python scripts/download_sources.py
python scripts/validate_data.py --check-raw
```

也可以手动下载到清单中的 local_path 后运行验证。若下载失败，不改用来源不明的镜像。若官方文件更新导致哈希不符，核验文档编号、修订、页码后添加新来源版本，不覆盖旧来源记录以维持旧标注。

`download_sources.py` 和 `validate_data.py --check-raw` 校验文件大小、PDF 文件头和 SHA-256，不解析实际页数或确认页面内容。页数需使用 `pdfinfo` 等 PDF 工具单独核对；文档编号、修订、适用范围和证据定位需检查对应页面。

2026-10-13 已重新获取两份固定版本 PDF，并独立核对实际页数及清单指定页面，详见 [核验计划、命令与结果](verification-2026-10-13.md)。这是工具与 AI 的来源核验记录，不代替人工领域复核。当前工具不做全量 PDF 解析；后续解析需要独立依赖和抽样检查。
